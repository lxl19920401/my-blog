个人博客网站 - 产品说明文档
一、产品概述
1.1 产品名称
MyBlog - 个人博客系统

1.2 产品定位
一个简洁、优雅的个人技术博客网站，用于记录和分享技术文章、学习笔记和生活思考。

1.3 目标用户
博主本人：日常写作和内容管理

读者群体：技术爱好者、学习者、同行开发者

1.4 核心价值
专注阅读体验，无广告干扰

简单易用，开箱即用

完全静态，部署简单

二、功能模块
2.1 首页模块
文章列表展示

以卡片形式展示所有博客文章

每张卡片包含：文章标题、发布时间、文章摘要、分类标签、预计阅读时长

支持文章置顶功能

支持分页加载，每页显示6-8篇文章

侧边栏信息

个人简介卡片：头像、一句话介绍

热门标签云：展示所有标签及使用频率

站点统计：文章总数、标签总数、最后更新时间

2.2 文章详情模块
内容阅读区

完整展示Markdown格式的文章内容

代码块语法高亮显示

支持图片自适应和点击放大

显示文章元信息：作者、发布时间、更新日期、所属标签

导航辅助

自动生成文章目录（Table of Contents），点击快速跳转

阅读进度条，显示当前阅读进度

上一篇/下一篇文章导航

相关文章推荐（基于相同标签）

互动功能

文章点赞功能（纯前端记录）

返回顶部按钮

2.3 标签模块
标签归档页

点击任意标签进入该分类下的文章列表

显示标签名称和关联文章数量

支持按热度或字母排序

2.4 搜索模块
全文搜索

支持按文章标题、内容、标签进行搜索

实时搜索结果展示

搜索结果高亮显示关键词

无结果时显示友好提示

2.5 关于模块
个人介绍页

博主详细个人介绍

技术栈展示

社交链接：GitHub、掘金、知乎、邮箱等

博客发展历程或里程碑

2.6 全局功能
主题切换

支持亮色/暗色两种主题模式

自动记住用户偏好设置

可选跟随系统主题

响应式适配

完美适配PC端（≥1024px）

适配平板端（768px-1023px）

适配手机端（≤767px）

三、内容管理方式
3.1 文章管理
所有文章以Markdown文件形式存放，每个文件包含：

Frontmatter头部信息（标题、日期、标签等）

Markdown格式的正文内容

3.2 新增文章流程
在指定目录创建新的.md文件

填写文章元信息（标题、日期、标签等）

使用Markdown语法撰写正文

保存文件即可自动生效

3.3 站点配置
通过配置文件可修改：

网站名称、Logo、描述

博主个人信息（头像、简介、社交链接）

每页显示文章数量

主题颜色等视觉设置

四、页面清单
页面	路由	说明
首页	/	文章列表主页
文章详情	/post/:id	单篇文章阅读页
标签归档	/tag/:name	按标签筛选文章
搜索结果	/search	文章搜索页面
关于	/about	个人介绍页
404	/404	页面不存在提示页
五、视觉设计规范
5.1 设计风格
整体风格：简洁、现代、留白充足

色调：中性色为主，强调色点缀

圆角：卡片和按钮使用圆角设计

阴影：卡片使用轻微悬浮阴影

5.2 配色方案
亮色模式

页面背景：白色或极浅灰色

卡片背景：白色或浅灰色

主要文字：深灰色

次要文字：中灰色

强调色：蓝色或任意品牌色

边框：浅灰色

暗色模式

页面背景：深灰或黑色

卡片背景：稍浅的深灰色

主要文字：浅灰色

次要文字：中灰色

强调色：亮蓝色

边框：深灰色

5.3 字体规范
标题字体：无衬线字体（如Inter、system-ui）

正文字体：衬线或无衬线均可，保证可读性

代码字体：等宽字体（如Fira Code、JetBrains Mono、Consolas）

5.4 布局规范
最大内容宽度：1200px

正文阅读宽度：720px-800px（保证最佳阅读体验）

卡片间距：24px

页面内边距：24px（手机端16px）

六、用户体验要求
6.1 加载性能
首屏加载时间控制在2秒以内

图片使用懒加载

路由切换平滑无闪烁

6.2 交互反馈
按钮和卡片有悬浮效果

点击有视觉反馈

页面切换有过渡动画

6.3 可访问性
支持键盘导航

合理的颜色对比度

图片提供alt属性

七、技术约束
7.1 技术栈要求
前端框架：Vue 3

构建工具：Vite

开发语言：JavaScript

路由：Vue Router

状态管理：Pinia（可选）

7.2 内容格式
文章格式：Markdown（.md文件）

元数据格式：YAML Frontmatter

7.3 部署方式
纯静态网站

可部署在：Vercel、Netlify、GitHub Pages、CloudFlare Pages等

八、非功能性需求
8.1 浏览器兼容
支持Chrome、Firefox、Safari、Edge最新版本

8.2 代码质量
代码结构清晰，组件化开发

必要的注释说明

8.3 文档要求
提供README.md项目说明

提供文章撰写格式说明

提供配置文件说明

九、产品优势
零成本部署：纯静态文件，无需服务器和数据库

写作友好：Markdown格式，专注内容创作

阅读体验：精心设计的排版，专注阅读

跨平台：PC、平板、手机完美适配

主题切换：亮色/暗色随心切换

SEO友好：静态页面，搜索引擎易于收录

十、后续扩展方向（可选）
评论系统集成（如Giscus、 utterances）

访问统计功能

RSS订阅功能

文章分享功能

站内通知功能
